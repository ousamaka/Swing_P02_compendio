# swing_c_p02_KassimiOusama

## Descripción del proyecto
Este proyecto es una aplicación de escritorio desarrollada para la gestión de apartamentos turísticos llamada **"SummerHeat"**. La herramienta permite realizar el alta de inmuebles, capturando datos del arrendador, detalles del piso, gestión de imágenes y cálculo automático de precios por día.

## Contenido de la publicación
El repositorio se organiza en las siguientes carpetas:
* **desarrollo**: Contiene el directorio del proyecto de Eclipse con el código fuente.
* **ejecutable**: Incluye el archivo .jar para ejecutar la aplicación.
* **documentación técnica**: Contiene el Javadoc generado de las clases.
* **documentos**: Incluye el documento sobre usabilidad de la interfaz.

## Desarrollo del proyecto
La aplicación se ha desarrollado utilizando **Java Swing**. Se han implementado interfaces mediante `GridBagLayout` para los formularios de datos y un `JTabbedPane` para mostrar el resumen de la información en pestañas. También se ha integrado la librería **FlatLaf** para mejorar el aspecto visual de la ventana principal.

## Despliegue
### Windows
Para ejecutar la aplicación en Windows, localice el archivo `.jar` en la carpeta `ejecutable` y ábralo con el entorno de ejecución de Java.

### Línea de comandos
Puede ejecutar la aplicación desde la terminal con el siguiente comando:
`java -jar ejecutable/swing_c_p02_KassimiOusama.jar`
