# swing_c_p02_KassimiOusama

## Descripción del proyecto
Este proyecto es una aplicación de escritorio desarrollada para la gestión de apartamentos turísticos llamada "SummerHeat". La herramienta permite realizar el alta de inmuebles, capturando datos del arrendador, detalles del piso, gestión de imágenes y cálculo automático de precios por día.

## Desarrollo del proyecto
* [cite_start]La aplicación se ha desarrollado utilizando Java Swing[cite: 15]. Se han implementado interfaces mediante GridBagLayout para los formularios de datos y un JTabbedPane para mostrar el resumen de la información en pestañas. También se ha integrado la librería FlatLaf para mejorar el aspecto visual de la ventana principal.
